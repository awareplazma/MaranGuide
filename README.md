# MaranGuide: Geospatial Tourism Prototype

## Project Overview

MaranGuide is a full-stack PHP application designed to digitize Majlis Daerah maran tourism information into a centralized, interactive web platform. It serves as a Proof of Concept (PoC) for community-driven social mapping and location-based service discovery.

## Key Features

- **Interactive Mapping**: Integrated Leaflet.js with custom markers for local landmarks and services.
- **Social Connectivity**: Built-in "Social Feed" logic for user-generated updates and community interactions.
- **External Integration**: "Deep Linking" to Google Maps for mobile-ready GPS navigation.
- **Responsive UI**: Developed using Google Materialize and Custom CSS for a mobile-first user experience.

## Technical Stack

- **Backend**: PHP (Core)
- **Frontend**: JavaScript (ES6), Google Materialize, Leaflet.js
- **Database**: MySQL (Relational Schema Design)
- **Environment**: Developed and tested on Localhost (XAMPP/WAMP)

## Current Status

This project is currently in the **Architectural Prototype** phase. It was developed to test real-time spatial data rendering and relational database queries for Majlis Daerah Maran use cases.
